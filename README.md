## 🚀 Proyectos destacados

### ⚡ [GraphStrike-Engine](https://github.com)
Una arquitectura de alto rendimiento escrita en **C++** que mapea rutas de ataque en entornos corporativos con Active Directory. Se sincroniza con bases de datos orientadas a grafos (**Neo4j**) para calcular los movimientos laterales más eficientes en tiempo real y bajo entornos con fuertes restricciones de seguridad.

### 🤖 [AegisGuard-LLM](https://github.com)
Un framework automatizado en **Python** diseñado para realizar pruebas adversarias contra modelos de Inteligencia Artificial corporativos. Automatiza el escaneo de inyecciones de prompts (Prompt Injections) y la evasión de telemetría, integrando suites avanzadas para evaluar la robustez de redes neuronales.

### 🛰️ [JSTap-Payload-Factory](https://github.com)
Un conjunto de herramientas modulares en **JavaScript/Express** enfocado en la preparación y entrega de payloads. Despliega hooks indetectables de recolección de telemetría dentro de navegadores objetivos, interceptando el tráfico del lado del cliente y enviando datos estructurados directamente a un backend protegido.
